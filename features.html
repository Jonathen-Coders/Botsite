Features of The C.B. include:

Implemented

  • Server management & moderation tools (ban, kick, timeout, purge, lockdown)
  • Economy system (coin balance, daily rewards, jobs, leveling)
  • Fun and interactive games (Math Game, Guess Game)
  • Color roles (15 customizable color roles via interactive buttons)
  • Auto-role configuration (automatic role assignment for new members)
  • Server statistics dashboard
  • Cross-server telephone communication
  • Raid protection configuration

Work in Progress

  • Customizable commands*
  • Ticket system*
  • Birthday system*

For more information, please visit our Discord server.

For a full list of commands, please visit our commands page.

* these are a work in progress and not yet fully implemented
