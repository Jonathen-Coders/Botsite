Commands for The C.B. are organized by category below.

Admin

  • /autorole-configure — Configure an auto-role assigned to new members
  • /autorole-disable — Disable auto-role for the server
  • /dashboard — View the server statistics dashboard

Economy

  • /balance — Check your or another member's coin balance
  • /daily — Claim your daily coin reward
  • /job — Manage your job for earning coins
  • /level — Check your or another member's level
  • /work — Work to earn coins

Moderation

  • /announce — Make an announcement in the server
  • /ban — Ban a user from the server
  • /colorroles — Create color roles with an interactive selection menu
  • /kick — Kick a user from the server
  • /lockdown — Temporarily lock down the server
  • /nickname — Change a member's nickname
  • /purge — Bulk delete messages from a channel
  • /timeout — Timeout a user for a specified duration
  • /raid-config — Configure raid protection settings

Misc / Utility

  • /ping — Check bot responsiveness
  • /help — Get help with bot commands
  • /invite — Invite the bot to your server
  • /sinvite — Get an invite to our support server
  • /uptime — Check how long the bot has been online
  • /github — View the bot's GitHub repository
  • /roles — View and manage server roles
  • /shards — View bot shard information
  • /site — Get a link to the bot's website

Fun / Games

  • /guess — Play a number guessing game
  • /mathgame — Solve linear equations (y=mx+b) in a math game
  • /telephone — Manage cross-server telephone calls

For more information, please visit our Discord server.
